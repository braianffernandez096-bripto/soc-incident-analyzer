# Carpeta del feed

Esta carpeta se monta **solo lectura** en el contenedor como `/feed`. Copia aquí tu archivo de indicadores
(por ejemplo `indicadores.json`) y activa `FEED_PATH=/feed/indicadores.json` en el `.env`. Guía: [docs/FEED.md](../docs/FEED.md).
`indicadores.ejemplo.json` es solo un modelo del formato.
